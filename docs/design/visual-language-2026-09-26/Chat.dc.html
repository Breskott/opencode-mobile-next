Fix the flaky checkout test. It fails about one run in five on CI.
The flakiness comes from CheckoutBloc racing the price refresh: applyCoupon() awaits the network before the total settles, so the assertion sometimes reads the old total. I made the test wait for the settled state.
checkout_test.dart+6−2 
await tester.pumpUntil(
  () => bloc.state is CheckoutSettled,
  timeout: const Duration(seconds: 5),
);
expect(find.text('$42.00'), findsOneWidget);
