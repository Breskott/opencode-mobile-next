# OpenCode Mobile 1.1.0 (DRAFT)

A full redesign, a built-in server for your phone, and a smarter Inbox and AI Team.

## Highlights
- **New look**: Geist type, graphite colours, optional liquid-glass bar, one design across every screen.
- **This phone runs OpenCode by itself**: guided setup on a built-in Ubuntu, no Termux needed. Termux users can use **Move from Termux**.
- **Inbox across servers** and **While you were away** show what needs you and what the app did for you.
- **AI Team in plain words**: tasks, steps, and a Needs you area; workers are their own conversations.
- **Faster chats**: instant open from your last read, much faster streaming.
- **More servers**: OpenCode 1 and 2, Claude Code, Pi and Codex through Paseo.

## Also new
- Voice in the message box with no time limit; the right voice pack is chosen for you.
- One **New conversation** chooser; move waiting prompts to another server.
- **Report a problem**, **AI setup** (review only), MCP catalogue, searchable settings.
- **What runs by itself** controls what the team and app do without asking.

## Fixed
- Reopening the app no longer cuts off a reply that is still running.
- Stopping a reply is no longer shown as Failed.
- The built-in server starts and reconnects on its own.
- Large text no longer overlaps rows; one status line and one time format.

## Changed
- **Background checks** moved into **Notifications › Saved servers**.
- Android **Clear storage** now opens a page first: export projects, clear cache only, or Delete everything.
- **Anthropic and Google use API keys**; browser sign-in does not load for them.
- Old Termux wizard and built-in server pages are replaced by **This phone**.

## Still off
- Merge undo and per-task cost (waiting on server support).
- AI setup Apply/Undo; session links that include the server address.
- Claude Code on this phone (ARM64 proof pending).
- Needs a device check: Move from Termux, setup on ARM64 phones, Manage space on other makers' Settings.

## Upgrading
- Installs over 1.0.44 only if signed with the same key. Saved servers, sign-ins and settings are kept.
- Termux users: nothing moves by itself. After a storage reset, tap **Allow access to Termux** again.
- Projects on the built-in server do not survive Clear storage or uninstall. Export first.
