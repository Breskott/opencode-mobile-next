# OpenCode Mobile 1.1.0 — release notes

Items marked *(needs a device)* were proven on host tests or an emulator only.
Nothing here has been published, tagged or signed yet.

## In short

- The whole app was redesigned: one look (Geist type, graphite colours, glass bar and sheets), one set of parts, and far fewer pages.
- **AI Team is now project-level**: you give a goal, a spec and milestones; it plans, works in lanes, checks, merges to a `dev` branch by itself, and asks you before anything reaches `main`. It runs on **this phone's own OpenCode** through a small built-in engine. *(Proven on an Android emulator only; needs a device.)*
- **This phone** can run OpenCode on its own inside the app, on a built-in Ubuntu, with no Termux. Termux still works, and there is a guided **Move from Termux**.
- The **Inbox** gathers what needs you across all your servers.
- Chats open instantly from what you last read, stream much faster, show live status on the message box's top edge, and never go silent.
- OpenCode 2, Claude Code, Pi and Codex servers are supported next to OpenCode 1, and the app protects your projects if Android's storage is cleared.

## New

### Getting started & This phone
- Set up OpenCode on this phone from inside the app: Ubuntu, Git, SSH, Python, Node and OpenCode are downloaded, checked and started for you. *(needs a device: full run on your own ARM64 phone)*
- Setup can be stopped and resumed, also after the app was closed, and shows the real step it is on.
- Phones with about 2 GB of memory can set up too (1,800 MB minimum), with a plain "may be slow on this phone" note.
- OpenCode is installed from a pinned, checksum-checked release and proven to answer before setup says "done".
- **Move from Termux**: review what moves (projects, plus settings and history kept as private backups), see sizes, copy with real progress, stop and resume, then connect. Termux itself is never changed. *(needs a device)*
- One **This phone** page for both hosts (built-in and Termux): Start, Stop, what is running (by kind, "18 of 32 background processes"), and per-part remove.
- Removing This phone keeps your projects by default; deleting them needs typing the name.
- The phone server repairs itself after a crash, within the limits you set (at most three tries, then it waits for you).
- The first microphone tap picks the right voice pack for your phone's memory, shows its size, asks before using mobile data, and starts listening when ready.
- Add a computer in one stepped path: what runs there, Tailscale if needed, pairing code or address, check, ready.

### Chat
- Chats open instantly with the end of the conversation as you last read it, while the fresh copy loads.
- Replies stream much faster and the screen stays smooth on long answers.
- One **New conversation** button with a chooser: Solo, Team, In a separate copy, or on a cloud machine where the server supports it.
- Voice is now a mode of the message box. Recording has no 30-second limit, and the transcript lands in your draft.
- One model sheet, one command sheet, and a conversation menu with **Go to** and **Do**.
- Waiting messages sit in one bubble, each with its state in words. A refused message says why and offers **Try again**.
- A finished turn folds its work into one line; explanations the agent wrote stay in view.
- Saved prompts now include your old drafts.
- Copy transcript hides text that is not your own.
- Move waiting prompts from a server you can't reach to a conversation on the connected one, with Undo.
- When a reply comes from OpenCode's free model, one quiet line says it is slower and links to provider sign-in.
- "Notify you when the agent needs you?" now sits in the status line above the reply, and no longer pushes the reply up.
- The phone stays awake while a reply runs on the built-in server.
- **Live status on the message box's top edge**: from the moment you send, one line shows what the agent is doing, with **Stop** on it. Stop is red and asks nothing extra. The line goes away when the turn ends.
- **Never a silent turn**: a reply that is slow to start says so in words; a turn cut by a dropped connection says that, not "failed".
- The **mic stays usable** while a reply runs.
- **One gutter and wider messages**: messages and request cards sit on the same 16 dp margin, and long messages use the full width.
- Team instructions and long work are folded; the worker page has **Collapse all**, the task title and plain role names.
- **Compact** asks first before it does anything.
- Code in messages gets a visible cue, and long links break instead of running off the screen.
- **Live updates recover from a stalled connection**: a stalled event stream is noticed and replaced, and updates for the open project keep coming while the main one is down.

### Work & Inbox
- **Inbox across servers**: one list ordered by urgency. Questions, other servers' requests, running work and finished work, newest first.
- **While you were away** rows show what the app did by itself (reconnects, restarts, approvals), with Undo where there is a real undo.
- Work shows one list with a plain line for what each row is doing, and "In other projects" for your other projects.
- The Project tab says "3 files changed" or "No changes", and "1 running" for terminals.
- One diff view and one file viewer everywhere.
- Search finds any setting, tolerates typos and works in English and Arabic; the same matcher powers the command sheet and the desktop palette.

### AI Team
Rebuilt around projects, in plain words. *(Proven on Android 14/15 x86_64 emulators only; a physical phone is still to be tried. needs a device)*
- **Turn on AI Team on this phone**: one button runs a safety check, starts a small built-in engine next to the phone's OpenCode, and says "Protected by this phone's Linux sandbox". Where Android blocks the stronger Landlock protection, the Linux sandbox is what protects it.
- **Projects** have a goal, a living **spec**, **milestones with criteria**, and phases. You approve the spec first; the plan comes after.
- **Plan card**: tasks with criteria, a role and repo for each, and risky phases marked "Review gate". Approve it, or edit it first.
- **Agents (roles)**: Planner, Worker and Checker, each with its own **model**. You can add roles and give a role its own instructions.
- **Single lane or Parallel lanes**: one task at a time, or several at once with a limit you set.
- **Checker**: every task is checked against its criteria. Findings are ranked, with **Fix**, **Re-check** and **Ignore**.
- **Automatic merges to `dev`** with a receipt for each (before and after commit). Your `main` branch is protected: **Promote dev → main** names the commits and needs your confirmation. Cancel leaves `main` untouched.
- **Budgets you set** (daily and total, or no limit). New work stops when one is reached and the project says so.
- **Resume**: after the app or the phone's OpenCode is stopped, interrupted work refetches its existing session and carries on; nothing is sent twice. When it cannot, it says why and waits for you.
- **Since you were away**: a digest of what merged, what failed, what was decided and what needs you.
- **Needs you** first on the project page, on the Work tab strip ("AI Team, 1 working"), in the Inbox, and in one ongoing notification.
- Each task is a conversation: its steps fold, and each worker has its own conversation, with plain role names and one live status.
- **Your chat goes first**: the team runs at the lowest CPU and disk priority, and a chat reply during a running lane answered in about 15 seconds in the emulator test.
- The team restarts itself after an update or crash, with a Start button on its page if it cannot.
- **What runs by itself**: how much the team decides alone (High, Balanced, Autonomous), always-allowed actions and background checks, each of which can be turned off.

### Servers & connecting
- One connection status line per screen, never two, with a plain diagnosis and **What to check** under Details.
- Servers: OpenCode 1, OpenCode 2 (beta and stable 2.0), Claude Code or Pi and Codex through a Paseo helper, all behind the same screens.
- Each server row says how many prompts wait for it and its state in words.
- Plain address errors, and a notice under the field when an `http://` address needs Tailscale's private `https://` one.
- Saved servers check in the background from **Notifications**.

### Settings & tools
- **Report a problem**: describe it, preview what is attached (secrets removed), then send as a prefilled GitHub issue, copy or share.
- **AI setup** (review only): see the settings that apply, your tool servers and suggestions for a server. Nothing is changed for you.
- **MCP**: an Add chooser and a catalogue, with a consent screen before anything is turned on.
- Remaining usage answers in plain words, per server, including Codex and the quota collector.
- **Manage space**: Android's "Clear storage" now opens an app page first (see Changed).
- Settings reorganised; Providers, Tools and Integrations rows lead with plain names.
- **One Notifications and background page** (what notifies, quiet hours, saved servers, keep running, What runs by itself) instead of several.
- **One search**: the header launcher; the extra search field inside Settings is gone.
- The Plugins page is gone. Its words find **AI Team**, and a server's own plugins are listed under **This server**.

### Look & feel
- New visual language: Geist type, graphite colours, one set of parts for every screen. Phone and tablet/PC layouts.
- **Liquid glass** on the bottom bar and sheets is part of the design and is always on. Crisp edges and moderate colour keep text readable. If glass ever crashed the app, it turns itself off and tells you.
- **Appearance** has three choices: light or dark, language, and **Motion** (Full, Calm, Off). The separate glass, celebration and vibration switches are gone.
- Secondary actions (Cancel, dismiss, inline buttons) are neutral; green marks only the main action.
- A flat background on every page, the same in Light and Dark.
- Taps show feedback on the very next frame; sheets, menus and dialogs share one motion.
- Large text (up to 200%) no longer breaks rows or buttons.

### Speed
- The app opens on the conversation titles it saw last time and never flashes empty placeholders over them.
- Start-up waits are done side by side, and hidden tabs do no work until opened.
- Tapping an Inbox row or notification lands on the exact card.
- Replies show their timing on This phone. The built-in server's speed was measured against Termux and is not the cause of slow replies.

### Safety & privacy
- Always-allowed actions and automatic acts are recorded, shown in the Inbox and confirmed before they happen.
- Diagnostics are saved on the phone with secrets removed, and sent only when you choose.
- Errors never show raw exception or server text; plain words come first and technical detail sits under Details.
- Plain words everywhere: forks read "Copy of ...", a server that is only an address reads "Computer at 192.168.1.5", times read "5 min ago / Yesterday", and timings sit under Details.
- Downloads ask before using mobile data. Every outside link goes through one checked path.

## Fixed

### Replies and chat
- Reopening the app no longer cuts off a reply still running on the server. It used to say "You stopped this reply".
- A reply you stop is no longer marked Failed in the Inbox or counted as "needs you".
- Chat model changes resend correctly; **Retry** works after a failure.
- The message box keeps its editor when the keyboard or layout changes.
- Waiting messages survive removing a server.
- Request cards and the composer no longer clip at 250% text.
- Reply speed on This phone is remembered after a relaunch.

### Connecting & This phone
- The built-in server now starts on its own at launch, like tapping Start, and reconnects after a slow first connect.
- A stale phone server is replaced instead of blocking a new one.
- If OpenCode is running but not answering, the page says so honestly instead of "stopped".
- No stopped page flashes before "Starting…".
- One reconnect row, not one per reconnect; offline Work no longer shows a second error panel.
- **Stop server** is a deliberate stop: no "starting again" banner and no automatic restart afterwards.
- A force stop reads "OpenCode Mobile was closed at …", and not "Android closed …".
- The connection line no longer sits on top of every setup step for a different server.
- Termux users get one cause and one fix (allow access, allow other apps, open Termux) instead of several vague pages.

### Look & text
- Welcome and lists no longer draw icons over text at large sizes.
- "Discard server changes?" only appears when something was entered.
- One time format across Inbox and Work, following your 12/24-hour setting.
- Setup estimates stay steady; the phone icon shows only for your own servers.
- Provider rows put environment names under Details; tool rows use plain words.
- No system focus frame around the app after a restart.

## Changed
- **Background checks is gone.** Its settings live in **Notifications › Saved servers**; the Inbox rows open there.
- **Clearing storage in Android now opens "Clear this app's storage" first.** You can export projects as a zip, clear the cache only, or Delete everything (confirm names the counts). Nothing is deleted silently. Anything you push to git and Termux are not affected.
- **Anthropic and Google sign-in uses API keys.** Browser sign-in for these two doesn't load on OpenCode 1.18, and OpenCode 2 has no built-in browser method for them either. Use an Anthropic API key or a Google AI Studio API key (billed separately). OpenAI and OpenCode's free model are unchanged.
- The agent-choice and connection-help pages are folded into Add server; the old Termux wizard and the built-in server page are replaced by This phone and phone setup.
- Running now is called **Running on this phone**, and Disconnect lives on the server's own page.
- Voice input sheet is gone; use the mic in the message box.
- Only Termux users who set up before: after a storage reset, re-allow Termux access (see Upgrading).
- Settings "Always allowed actions" is now inside **What runs by itself**, which lives on the Notifications and background page.
- **AI Team works on projects**, not single tasks, and uses the phone's own OpenCode. The older in-app team add-on and its per-task setup are replaced.
- **Appearance** lost the Glass effects, Celebrations and Vibration rows (see Look & feel). Old settings are read as Motion.

## Known limitations / still off
- **AI Team is emulator-proven only** (Android 14 and 15, x86_64). A full single-lane project ran from create to Done, and a Parallel-2 project was fixed and re-run after the last emulator test; it has not run on a physical ARM64 phone. *(needs a device)*
- **AI Team needs a model with a key.** Each role (Planner, Worker, Checker) must have a model set; on a fresh install, "Team's model" alone was not enough and each role needed the model chosen. Free-model limits can stall it.
- **Work pauses while Android stops the app** (battery saver, background limits, the 6-hour cap on background services in Android 15). It resumes when you open the app or Android allows, and the digest records the gap.
- Merges to `dev` happen by themselves, with a receipt but no confirmation. Only `main` needs your confirm.
- **Merge undo** is off until a server keeps durable merge receipts. **Per-task cost** is off until a server keeps a per-task ledger; usage is shown as estimates only.
- **AI setup is review-only**; it cannot apply or undo changes.
- **Session links that include the server address** are off until verified; links without one still work.
- **Claude Code on this phone** is not offered: the ARM64 proof failed at its install step. Claude Code works through a Paseo helper on a computer.
- **Move from Termux** and **This phone setup on real ARM64 phones** were verified on host tests and an emulator. *(needs a device)*
- **Manage space page on other phone makers' Settings**, the notification permission prompt on "Notify me", and voice downloads over mobile data. *(needs a device)*
- Emulator only: Light theme with glass crashed one emulator once; not seen on a phone. If it happens, the app turns glass off by itself.
- **Arabic is not fully translated**: the voice packs and the copy of several new pages, including the AI Team project pages, are English-first; the list is in `docs/localization-todo.md`.
- Some AI Team rough edges remain from the last emulator run: a few leftover "Demo" labels, a raw working-folder id as a project name in the picker, repeated "Restarted by itself" rows in the Inbox, and a Create project sheet that can be sent without "Where it runs".

## Upgrading
- Installs over 1.0.44 when it is built with the same signing key; a different key needs an uninstall and loses local data. Check the certificate before handing out the APK.
- Your saved servers, sign-ins, conversations cache and settings are kept. Queued prompts are kept.
- Termux users: nothing moves by itself. Open **This phone › Move from Termux** when you want to switch. Termux and its projects stay as they are.
- After a **storage reset**, the app asks to re-allow Termux access (**Allow access to Termux**). Android removes that permission when storage is cleared; the Termux server and its password stay.
- Built-in server projects live in app storage; they survive removing This phone but not Android's Clear storage or an uninstall. Export first.

## Version
**This is 1.1.0.** Since 1.0.44 most screens were replaced, the app gained a second way to run OpenCode (in the app), a project-level AI Team and a new storage behaviour, and some pages were removed. Patch numbers (1.0.x) were used for fixes and small steps; this is a minor step. Nothing here breaks saved data.
