# OpenCode Mobile 1.1.0

A full redesign, a built-in server for your phone, a project-level AI Team, and a smarter Inbox and chat.

## Highlights
- **AI Team for projects**: give a goal, spec and milestones; it plans, works in one or several lanes, checks each task, merges to `dev` with receipts, and asks you before anything reaches `main`. You set the models per role and the budgets. It resumes after interruptions and shows **Since you were away**. Runs on the phone's own OpenCode with a built-in engine. *Emulator-proven (Android 14/15 x86_64); needs a device.*
- **New look**: Geist type, graphite colours, glass bar and sheets, flat backgrounds, neutral secondary actions. Appearance is just theme, language and Motion.
- **This phone runs OpenCode by itself**: guided setup on a built-in Ubuntu, no Termux needed. Termux users can use **Move from Termux**.
- **Chat**: instant open, faster streaming, live status and **Stop** on the message box's top edge, never a silent turn, the mic stays usable, live updates recover from a stalled connection.
- **Inbox across servers** and **While you were away**.
- **More servers**: OpenCode 1 and 2, Claude Code, Pi and Codex through Paseo.
- **Settings**: one Notifications and background page, one search, no Plugins page.

## Fixed
- Reopening the app no longer cuts off a reply that is still running; stopping a reply is not shown as Failed.
- The built-in server starts and reconnects on its own; Stop server stays stopped.
- Large text no longer overlaps rows; one status line and one time format.

## Changed
- **Background checks** moved into **Notifications and background**.
- Android **Clear storage** opens a page first: export projects, clear cache only, or Delete everything.
- **Anthropic and Google use API keys**; browser sign-in does not load for them.

## Known limitations
- AI Team needs a model with a key, pauses while Android stops the app, and has not run on a physical phone.
- Arabic is not fully translated. Merge undo, per-task cost and AI setup Apply are off.
- Needs a device check: Move from Termux, setup on ARM64 phones, Manage space on other makers' Settings.

## Upgrading
- Installs over 1.0.44 only if signed with the same key. Saved servers, sign-ins and settings are kept.
- Projects on the built-in server do not survive Clear storage or uninstall. Export first.
