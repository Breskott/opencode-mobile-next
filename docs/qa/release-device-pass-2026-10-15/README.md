## Bugs

- **P0-1 AI Team cannot be turned on while the phone runs Older OpenCode 1.19.0.** Step 4 fails with `unsupported_server_version` (twice). The move offer still promises "AI Team keeps working", and the screen shows only "Start again", which cannot help. Fix direction: either hide/replace the "Turn on AI Team" door on Older OpenCode with "needs OpenCode 2 - Move to OpenCode 2", or make it work. (rel-18, rel-19)
- **P0-2 (data loss risk) Chats made on Older OpenCode vanish after "Move to OpenCode 2" when OpenCode 2 ever started on this phone before.** My path: default setup started OpenCode 2 first, then I switched to Older OpenCode and chatted, then moved to OpenCode 2. The conversation was not carried (0 conversations after 40 s). Likely cause: `opencode_history_copy.dart` only copies when OpenCode 2's `opencode.db` does not exist yet (per `docs/qa/oc2-switch-keeps-chats-2026-10-14`), and setup always starts OpenCode 2 first. Because first-run setup cannot start on Older OpenCode (no choice on screen), every phone that picks Older OpenCode went through OpenCode 2 first, so this is the normal path, not an edge case. Not verified: the migration status line, or whether the chat is still in OpenCode 1's database. Needs a re-run on a phone that first-ran on OpenCode 1 (an upgraded one) to see if the guard passes there. (rel-24)
- **P1-1 Turning AI Team on OpenCode 2 failed with `engine_in_use` three times in a row** after the failed OpenCode 1 attempt (2b) left an engine running ("AI Team didn't start. The team's engine didn't start on this phone. OpenCode is back on."). Only force-stopping the app and reopening it let the turn-on pass. "Start again" never recovers. (rel-26, rel-27, rel-28)
- **P1-2 "Asks first" never asked.** OpenCode 2 ran shell and file writes (including `/etc/...`) with the "Asks first" chip showing. Either the mode is not applied to OpenCode 2 sessions or the server auto-allows; this makes the widget Allow once flow unreachable. (rel-62)
- **P2-1 Run-from-widget timer missing.** "Connects when you tap" shows, but no elapsed timer ticks while "Stay connected" is off.
- **P2-2 Runtime choice is hidden at first run.** The brief's "choose Older OpenCode" step has no UI on the setup screen; only This phone > "Switch to Older OpenCode" after OpenCode 2 is already installed and started. The move offer and a second "Switch to OpenCode 2" row appear together on the older runtime (duplicate door).
- **P2-3 Spec shaping took about 9 min** with the free model and showed "Shaping the spec" with no progress (11:46 to 11:56).
- **P3-1** Installed line omits Python and AI Team after Add tools (they are installed).
- **P3-2** Conversations widget: picker preview is only the app logo, its name is the description sentence ("Your newest OpenCode conversations, one tap away."), it drops narrow (label wraps "Backg round"), and with no chats it shows the AI Team project row.
- **P3-3** Aurora drift selection check badge overlaps the preview's top pill (rel-70).
- **P3-4** Project header says "0 working" for 9 minutes after the work finished (label stale).
