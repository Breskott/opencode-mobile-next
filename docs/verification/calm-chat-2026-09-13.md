Finish line: conversation reading and writing dominate, while task details and secondary prompt operations remain available through labeled disclosure. Non-goals: transport, persistence, theme palette, shared Markdown widgets, or suppressing permission/error/Stop controls.

Based on the delivered `e39d7f0` candidate and fresh `before-chat` captures. The previous title occupied two oversized lines, a zero-running Tasks icon competed with the title, and prompt tools exposed an ungrouped list.

## Implemented

- Use a compact, single-line conversation title. The full title is available through its tooltip and at the top of Session actions. Text scaling follows the existing Material behavior; transcript/input text scaling is unchanged.
- Show the app-bar Tasks shortcut only when related agents or shells are running. Results in Session actions continues to open the same task sheet when idle.
- Keep model selection, the full-width multiline editor, attachment access and Send/Stop directly available. Show expand when a draft exists; the Commands entry still exposes the full-screen editor for an empty prompt.
- Show context percentage alongside the existing warning meter from 70% usage; routine values remain in Context usage.
- Keep common input choices available in Prompt tools. Group context capsules, web sources and voice conversation under Advanced; group history, older drafts, stash and clear text under Prompts. Existing capability checks and disabled-state explanations are preserved.
- Summarize running tool groups rather than automatically opening every tool row. The header still names active work and status. Errors and output files reveal the group; an explicit user expansion choice survives later tool updates.

No new localization keys, credentials, storage formats or controller behavior. Existing message action buttons remain visible and accessible. The shared code-block toolbar is outside this branch and was raised with the coordinator.
