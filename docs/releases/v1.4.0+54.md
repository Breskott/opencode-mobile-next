# OpenCode Mobile 1.4.0+54

Act on your agents from the home screen, hand a conversation to another agent, and give the app a live background, all on a cleaner chat screen.

## What changed for you

- New **home-screen widgets**: **Allow** a request, **Stop** or **Steer** a reply, or start one by voice, without opening the app.
- **Continue with…** hands a conversation to another agent, like Codex to Claude Code.
- A **live background** in 20 looks, a **Text size** setting and a one-line chat header.
- We're preparing to **end support for OpenCode 1**: new phones start on OpenCode 2, and **AI Team** runs there too.
- Sending while an agent works **steers** it; Codex chats steer too.

## Technical changes

### Added
- Home-screen widgets:
  - **Conversations** comes in three sizes: 1×1 (status and counts), 2×2 (the top conversation) and 4×2 (a list).
  - **Allow once**, **Reject**, **Stop**, **Steer** and **Resume** run from the widget, opening a short connection for that one tap.
  - A live timer counts while a reply runs. A running card slides between conversations.
  - **Usage** shifts from green to amber, then grey, as a limit runs down.
  - A style window opens when you place a widget: background (solid, tinted or transparent) and accent (wallpaper, app theme or a preset).
  - Widgets follow your wallpaper colours.
- **Continue with…** in a conversation's ⋯ menu:
  - It writes a masked record of the conversation into the project and starts the chosen agent with an editable first message.
  - The two conversations link to each other.
  - It works from OpenCode, OpenCode 2, Codex and agent conversations, toward Claude Code.
  - After a provider error, the conversation offers **Continue with another agent**.
- **Live background** (Settings › Appearance › Effects):
  - 20 looks: ambient, industrial (including Matrix rain) and premium. **Aurora drift** is the default.
  - The picker shows live tiles and a full-screen preview, with three intensities. Animation runs at the screen's refresh rate.
  - It pauses when the app is not in front or motion is reduced, and text keeps its contrast.
- **Text size**: Smallest, Small, Default or Large, for this app only.
- AI Team:
  - Runs on OpenCode 2, with the same tool limits per role.
  - Team settings choose a model for each role (Planner, Worker, Checker).
  - Project setup:
    - pick the project folder;
    - a new folder starts as a git project;
    - an empty project offers **Make the first commit for me**;
    - planning starts with sensible defaults, and the spec starts from your task.
  - An interrupted task offers **Resume**. Shaping a spec shows how long it has taken.
- OpenCode 2 (support for OpenCode 1 is being retired):
  - New phones start on OpenCode 2. OpenCode 1 stays available as **Older OpenCode** for now; a later release ends its support.
  - A phone still on OpenCode 1 shows one quiet **Move to OpenCode 2** offer that brings its conversations along.
  - The move never drops history. When OpenCode 2 already has its own conversations, it explains that and offers **Stay on Older OpenCode**.

### Changed
- Chat header: one line for the title, one quiet line for the project, and the server only when several are connected. The context ring appears from 50%, and **Collapse steps** only when there are open steps.
- Small animations when things appear or change across the app.
- Sending during a running reply steers wherever the agent supports it (OpenCode 2, Codex, Claude Code). The queue choice is gone. OpenCode 1 still sends after the reply.
- Light mode panels sit on a soft off-white. Failures read in neutral words, never red.
- A Codex chat says **Ask Codex…** and shows its own connection everywhere, even when opened from a notification.
- Visual polish from a full UI audit: alignment, spacing and icons that grow with text size.

### Fixed
- **Asks first** asks before shell commands and file writes on OpenCode 2.
- A running command no longer triggers "the model is taking longer". A busy phone server is no longer called offline or not answering.
- AI Team turns on with Older OpenCode again, and a failed start no longer leaves it stuck.
- Setup repairs packages left half-installed by an interrupted install.
- An agent card that can't be drawn is one quiet line instead of raw fields.
- Device-code sign-in (ChatGPT/OpenAI) finishes while you wait, and the code can be copied.
- `@` mentions and the project file picker in the message box.
