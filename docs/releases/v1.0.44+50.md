# OpenCode Mobile 1.0.44+50

This Android release rebuilds the conversation screen around how a person reads it, adds new servers and agents to connect to, and makes working across several projects possible.

- The conversation reads as turns, not boxes. Everything an agent does between two things it says folds under one line that names the step in hand and opens to show every step in order. Your own messages stand out. One Copy and one menu per turn.
- Errors are said in plain words with what happens next, once, with the server's exact text one tap away. A failed compaction can be retried from its own line.
- Steering messages sent in a row reach the agent as one. A message waiting for the agent is shown once.
- Attach several photos at a time; photos are scaled for a model before sending. Excel and Word files attach as the text they contain.
- OpenCode 2.0 servers are supported alongside the earlier beta. A model's fast mode is its own choice in the picker.
- Claude Code, Codex, Pi and other agents can be reached through a Paseo daemon on your own network. Claude Code can be installed on the phone itself.
- Servers found on this phone come first, with connect, start, restart, stop and forget in place. The phone server's password is recovered automatically.
- Settings, first run and search were reorganised around four ideas: Server, Project, Conversation and Inbox.
- Several projects at once: recent projects are one tap away on Work, conversations running in your other projects are listed there, and a project where an agent is waiting for you says so.
- Approvals can be automatic for a whole server, behind a confirmation. The Tasks sheet separates what is running from what finished, by outcome.
- Twenty-six more themes, each checked for readable contrast. The high accuracy voice model is offered by the phone's memory, as intended.

OpenCode Mobile is an independent community app built with substantial AI assistance. It is not affiliated with the official OpenCode project.

## Scope

Android is the supported release platform. Desktop builds remain experimental and have not been hardware-tested. Browser support is in active development and is not included in this Android download. AI Team / Gas City integration, the Paseo connection and Claude Code on the phone are experimental; this release does not promise complete server feature parity. Working across projects is a first step: opening a conversation in another project still makes that project the current one, and other projects' approvals are shown in the app but do not yet raise system notifications.

"Approve everything" lets agents run commands and change files without asking. Use it only for servers and projects you can afford to break.

This APK uses the normal Flutter release build. It is not a Shorebird release and does not establish an over-the-air patch baseline.

## Install or update

Download `opencode-mobile-1.0.44+50.apk` below. Public APK updates retain the existing public signing certificate:

`842284B27AA297FB74CF831779FD16498517E1BC2104451459FEC2EA7AC11D1C`

Maintainer builds use a separate certificate beginning `2D010C21`; those installations need the matching maintainer APK. Android cannot update one certificate lineage with another. Keep your existing installation and its data if Android reports a signature mismatch; obtain an APK matching the signer shown in Settings → About.

The build workflow appends the actual source commit, package identity, certificate and APK checksum below. Publishing requires successful quality checks and verification of the exact signed artifact. Report reproducible problems through the app's Report a bug action.
