# OpenCode Mobile 1.0.43+49

This Android release makes everyday coding easier to navigate: connect to a server, resume a conversation, write a prompt and review its changes.

- A detected Termux server has a visible connection action. Additional setup choices appear when needed.
- Workspace, conversation and file screens show primary actions first. Search modes, extra actions and detailed change totals remain available on demand.
- Phone storage explains locally retained app data and provides scoped cleanup choices. It does not manage arbitrary files on your device or server.
- Connection readiness no longer depends on a server returning an optional version string, preventing a healthy server from getting stuck on the connecting screen.

OpenCode Mobile is an independent community app built with substantial AI assistance. It is not affiliated with the official OpenCode project.

## Scope

Android is the supported release platform. Desktop builds remain experimental and have not been hardware-tested. Browser support is in active development and is not included in this Android download. AI Team / Gas City integration remains experimental; this release does not promise complete server feature parity.

This APK uses the normal Flutter release build. It is not a Shorebird release and does not establish an over-the-air patch baseline.

## Install or update

Download `opencode-mobile-1.0.43+49.apk` below. Public APK updates retain the existing public signing certificate:

`842284B27AA297FB74CF831779FD16498517E1BC2104451459FEC2EA7AC11D1C`

Maintainer builds use a separate certificate beginning `2D010C21`; those installations need the matching maintainer APK. Android cannot update one certificate lineage with another. Keep your existing installation and its data if Android reports a signature mismatch; obtain an APK matching the signer shown in Settings → About.

The build workflow appends the actual source commit, package identity, certificate and APK checksum below. Publishing requires successful quality checks and verification of the exact signed artifact. Report reproducible problems through the app's Report a bug action.
